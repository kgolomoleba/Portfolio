// 05 — Reflections

STAR Method Reflections

R_01

Coding My CV in Markdown

S
Situation

As part of my Work Readiness module at CPUT, I was required to create a professional digital portfolio. This included coding my CV using Markdown language and hosting it on GitHub — a format I had not previously used for professional document creation.

T
Task

I needed to translate my existing Word-based CV into a properly structured Markdown file using GitHub Flavoured Markdown (GFM), ensuring it was readable, professional, and included working hyperlinks to my GitHub repositories and profiles.

A
Action

I researched GFM syntax and practised using headings, tables, bullet lists, bold text and inline links. I structured my CV systematically — starting with contact details, then education, technical skills, projects and references — iterating until the formatting rendered cleanly on GitHub.

R
Result

I successfully produced a professional, well-structured CV in Markdown that renders correctly on GitHub. The process gave me a new documentation skill directly applicable to software development — README files, wikis, and pull requests all use the same syntax I now understand confidently.

Mock Interview Video Experience

S
Situation

T
Task

A
Action

I prepared by researching common junior developer interview questions, structured my answers using the STAR method, and practised articulating my technical skills and project experience. I set up a professional recording environment and reviewed the footage before finalising my submission.

R
Result

R_03

Deploying to GitHub Pages

S
Situation

My work readiness assessment required me to publish my digital portfolio as a live, publicly accessible website — not just files stored in a GitHub repository. I needed to use GitHub Pages, a deployment feature I had not previously configured for a personal portfolio.

T
Task

I needed to create and structure a GitHub repository correctly, build a functional HTML portfolio site, enable and configure GitHub Pages, and ensure the live URL displayed all required content — CV, projects, mock interview video and STAR reflections.

A
Action

I created a dedicated repository, structured the project with an index.html and cv.md file, then navigated to the repository Settings → Pages to enable deployment from the main branch. I tested the live URL after deployment and verified all links, sections and content rendered correctly.

R
Result

My portfolio was successfully deployed and is now publicly accessible via a GitHub Pages URL. This gave me hands-on experience with static site deployment — a directly transferable skill for hosting projects, documentation sites and client deliverables in my future career as a developer.
